### 支持矩阵

| GitLab | Access Token / 用户名密码 | 是 |

### 关键实现

- 编辑页动态表单：平台切换联动认证方式选项，按 `showTokenField` / `showUserPassFields` / `showBaseUrlField` 控制字段显隐

## Git 仓库首页 — 修复搜索不生效

- 根因：`onSearchInput` 未更新 `isList` 标志位
  - `onShow` → `checkToken` 会把 `isList` 设为 false，异步 `loadRepos` 再设回 true
  - 在此间隙输入搜索，`filteredRepos` 已更新但 `isList` 仍为 false，列表区域不渲染
- 修复：`onSearchInput` 中同步更新 `isList: filtered.length > 0`
- 同时修复 `loadRepos`：`isList` 改为按过滤后结果判断，`showNoResult` 在有搜索词且无结果时置 true

## WXML 编码规范（重要）
- WXML 模板 `{{ }}` 内**不支持**三元表达式 `? :`、`===`、`!`、`&&`、`||` 等运算符
- 所有复杂逻辑必须在 TS 里预计算为布尔值或字符串，模板只做简单展示
- 常见做法：`isXxx: boolean` + `xxxClass: string` + `xxxText: string`
