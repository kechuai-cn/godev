## Git 仓库首页 — 修复搜索不生效

- 根因：`onSearchInput` 未更新 `isList` 标志位
  - `onShow` → `checkToken` 会把 `isList` 设为 false，异步 `loadRepos` 再设回 true
  - 在此间隙输入搜索，`filteredRepos` 已更新但 `isList` 仍为 false，列表区域不渲染
- 修复：`onSearchInput` 中同步更新 `isList: filtered.length > 0`
- 同时修复 `loadRepos`：`isList` 改为按过滤后结果判断，`showNoResult` 在有搜索词且无结果时置 true
