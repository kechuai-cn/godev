# Go Dev 微信小程序

## 首页

**pages/home/page**

承载所有入口

目前计划支持:

1. Git仓库管理
2. 验证器管理
3. 文本大模型使用
4. 图片生成大模型使用
5. 视频生成大模型使用

## Git 仓库首页

支持多账号仓库浏览, 顶部支持切换账号, 比如Github 账号切换到 Gitee 账号

仓库首页罗列出所有仓库, 包括组织的

如果没有账号, 则展示跳转到令牌录入页面的提示(就是去Git 仓库令牌管理页面)

## Git 仓库令牌管理页面

令牌列表, 支持包括: GitHub Gitee 等等令牌录入, 及其编辑, 删除
