# Go Dev 微信小程序

- 使用 Github Personal Access Token 进行认证
- 首页可以直接显示所有的仓库，支持下拉刷新、上滑加载更多
- 首页有个搜索按钮可以跳转到搜索页面
- 搜索页面可以基于关键字搜仓库名、仓库描述匹配的仓库，搜索页面支持下拉刷新、上滑加载更多
- 首页，如果没有授权或者认证无效，会提示并暂时跳转到认证页面的按钮
- 搜索页面的仓库和首页的仓库都跳转到仓库详情页面
- 搜索页面的仓库列表支持收藏（star）和取消 star，
- 首页会展示一个跳转到收藏列表的按钮，点击后跳转到收藏列表页面
- 收藏列表页面展示所有收藏的仓库，支持下拉刷新、上滑加载更多
- 收藏列表页面的仓库支持取消收藏
- 仓库详情页面展示仓库的基本信息，包括仓库名、描述、语言、星标数、fork 数、最近更新时间等
- 仓库详情页面展示仓库的文件和目录，支持递归查看子目录
- 代码浏览页面的文件点击跳转到文件详情页面
- 代码浏览页面的文件详情页面展示文件的内容，支持代码高亮
- 查看文件的内容
- 支持递归查看子目录

## 页面：

- pages/home
- pages/search
- pages/starred
- pages/repo
- pages/file
- pages/auth
